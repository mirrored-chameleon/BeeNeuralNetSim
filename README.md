# Bee neural net
### 🐝 The first SwiftNN test repo!! (That's a mouthful)
This is the first official SwiftNN test repo, built for STS. It is a simple simulation with a bee trying to find it's way throught the momumental task of finding a flower and returning it to the hive. At the moment it is just here for the science talent search judges, but if any one else stumbles upon this repo, feel free to clone this repo and give it a try. Enjoy!
I have also now created a link for the repo, so feel free to check it out on https://bee-neural-net-sim.onrender.com/.
